# Media Assets

Drop your captured media here so the README can display them.

Expected files (referenced by `README.md`):

- `screenshot-title.png` — the title screen
- `screenshot-gameplay.png` — the 3-viewport gameplay (SIM-Apotek + prescription + shelf)
- `screenshot-dispensing.png` — the etiket / mortar mini-game
- `gameplay.mp4` or a YouTube/Loom link — a short (30–60s) gameplay clip

## How to capture

1. Run the game locally: `npm run dev` and open http://localhost:5173
2. Screenshots: use your OS screenshot tool (macOS: Cmd+Shift+4).
3. Video: use QuickTime (macOS), OBS, or Loom. Keep it under ~60s.
4. Save the files into this `docs/` folder using the names above.
5. Commit and push — the README image links will resolve automatically.

> These are placeholders because screen capture must be done on a machine
> with a display; it cannot be auto-generated by the build.
